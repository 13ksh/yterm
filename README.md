# KPixel 채널 필터

[del.kpixel.net](https://del.kpixel.net)에 유튜브 채널 ID(`UC…`)를 넣으면 `t` 또는 `f`가 내려옵니다. 이 확장 프로그램은 **`t`인 채널만** 다음 화면에서 숨깁니다.

- 댓글
- 커뮤니티 게시물
- 쇼츠 피드
- 홈·구독함·추천 같은 동영상 피드

**검색 결과는 숨기지 않습니다.** 검색으로 찾은 뒤 채널 페이지로 들어가면 그 채널의 영상·쇼츠·게시물은 그대로 보입니다. 검색에서 연 쇼츠 한 편은 보여 주고, 이어서 뜨는 다른 `t` 쇼츠는 건너뜁니다.

API가 죽거나 `invalid`처럼 `t`/`f`가 아니면 숨기지 않습니다(fail-open).

## 설치

1. 이 저장소를 받습니다.
2. Chrome / Edge / Brave에서 `chrome://extensions`를 엽니다.
3. **개발자 모드**를 켭니다.
4. **압축해제된 확장 프로그램을 로드합니다**를 누르고, `manifest.json`이 있는 이 폴더를 선택합니다.
5. [youtube.com](https://www.youtube.com)을 새로고침합니다.

툴바 아이콘에서 필터 on/off, 이 페이지에서 숨긴 개수, 채널 ID 직접 조회, 캐시 비우기를 할 수 있습니다.

## 동작

| 페이지 | `t` 채널 |
| --- | --- |
| 검색 `/results` | 그대로 표시 |
| 홈, 구독함, 탐색, 추천 | 영상·쇼츠·게시물 숨김 |
| 시청 페이지 | 댓글·추천·게시물 숨김. 지금 보는 영상은 유지 |
| `/shorts` | 피드의 `t` 쇼츠 숨김/건너뜀 |
| 채널 페이지 | 영상·게시물은 유지. 다른 `t` 채널 댓글만 숨김 |

채널 ID는 카드/댓글의 Polymer `data`, `/channel/UC…` 링크, `@핸들` 순으로 읽습니다. 핸들만 있으면 같은 유튜브 페이지를 한 번 받아 `UC` ID로 바꿉니다.

조회 결과는 12시간 캐시합니다. `https://del.kpixel.net/{채널ID}`에 `GET`만 합니다.

## 미리보기 / 테스트

```bash
npm test
npm run preview
```

미리보기는 `http://127.0.0.1:43187` 에서 피드/검색 차이를 보여주고, 실제 API도 대신 조회합니다.

## 파일

- `manifest.json` — Manifest V3
- `background.js` — API 조회와 캐시
- `content.js` / `hide.css` — 유튜브 DOM에서 항목 숨김
- `shared.js` — 페이지 판별, 채널 ID 추출, `t`/`f` 파싱
- `popup.html` — 상태 창
