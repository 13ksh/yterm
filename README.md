# 댓글나무

유튜브 댓글을 이런 트리로 만들어 복사합니다.

```
2026 아우라 노래 모음집
├─@hsh 이거 진짜임
│  ├─@사람 ㄹㅇ
│  ├─@disco 그건 아닌듯
│  ├─@licen 뭔 소리임;
│  │  └─@hsh 왜 시비임
│  └─@86 아하
└─@eos 저게 뭐임
    ├─@hdd 노래잖아
    └─@천재 영상임
```

유튜브는 대댓글을 한 단계만 보여 줍니다. 댓글나무가 `@닉네임` 멘션을 보고 그 아래 칸에 다시 넣습니다.

## 실행

```bash
npm install
npm run dev
```

브라우저에서 [http://127.0.0.1:43147](http://127.0.0.1:43147) 을 엽니다.

1. 페이지에 예시 트리가 바로 나옵니다.
2. 유튜브 영상 주소를 붙여 넣고 **트리 만들기**를 누릅니다.
3. **복사** 또는 `.txt`로 저장합니다.

## 옵션

- **인기 댓글 / 최신 댓글**
- **댓글 20 / 40 / 80개** (원댓글 기준)
- **@멘션으로 묶기** — `@licen 왜 시비임` 같은 답을 `licen` 아래로 넣습니다
- **좋아요 표시**

댓글은 불러올 때만 읽고 서버에 저장하지 않습니다. 유튜브가 데이터센터 IP를 막으면 예시 트리로 형식을 볼 수 있습니다.

```bash
npm test
npm run build
```
