# 댓글나무 + ASCII 유튜브

유튜브 댓글을 이런 트리로 만들어 복사합니다.

```
2026 아우라 노래 모음집
├─@hsh 이거 진짜임
│  ├─@사람 ㄹㅇ
│  ├─@disco 그건 아닌듯
│  ├─@licen 뭔 소리임;
│  │  └─@hsh 왜 시비임
│  └─@86 아하
└─@eos 저게 뭐임
    ├─@hdd 노래잖아
    └─@천재 영상임
```

유튜브는 대댓글을 한 단계만 보여 줍니다. 댓글나무가 `@닉네임` 멘션을 보고 그 아래 칸에 다시 넣습니다.

## 웹 — 댓글 트리

```bash
npm install
npm run dev
```

브라우저에서 [http://127.0.0.1:43147](http://127.0.0.1:43147) 을 엽니다.

1. 페이지에 예시 트리가 바로 나옵니다.
2. 유튜브 영상 주소를 붙여 넣고 **트리 만들기**를 누릅니다.
3. **복사** 또는 `.txt`로 저장합니다.

### 옵션

- **인기 댓글 / 최신 댓글**
- **@멘션으로 묶기** — `@licen 왜 시비임` 같은 답을 `licen` 아래로 넣습니다
- **좋아요 표시**

댓글 개수 제한은 없습니다. 이어지는 페이지와 대댓글을 끝까지 가져오며, 아주 긴 영상은 몇 분 안에 모은 만큼을 보여 줍니다.

댓글은 불러올 때만 읽고 서버에 저장하지 않습니다. 유튜브가 데이터센터 IP를 막으면 예시 트리로 형식을 볼 수 있습니다.

## CLI — 컬러 ASCII 플레이어 (8 FPS)

터미널에 유튜브를 컬러 아스키 아트로 그립니다. 프레임은 `▀` 반쪽 블록과 24비트 ANSI 색이고, 아래 YouTube 빨간 `%` 게이지가 진행률을 보여 줍니다.

영상 파일을 저장하지 않습니다. `yt-dlp`로 스트림 URL만 얻은 뒤 `ffmpeg`가 raw RGB를 파이프합니다.

필요: `ffmpeg`, 유튜브를 볼 때는 `yt-dlp`.

```bash
npm run ascii -- --demo
npm run ascii -- https://www.youtube.com/watch?v=VIDEO_ID
npm run ascii -- ./clip.mp4
```

조작: `space` 일시정지, `q` 종료. 기본 8 FPS.

```bash
npm run ascii -- --help
```

`--demo` 는 ffmpeg `testsrc2` 컬러 패턴이라 네트워크 없이 게이지와 8 FPS를 확인할 수 있습니다.

유튜브가 데이터센터 IP에서 봇 확인을 걸면 스트림을 열 수 없습니다. 그때는 `--demo` 를 쓰거나, 로컬에서 `yt-dlp` 브라우저 쿠키를 넘기세요. 어느 쪽이든 이 도구는 영상을 파일로 저장하지 않습니다.
